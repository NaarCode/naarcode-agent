# معماری و گردش‌کار

نسخه بررسی‌شده، نقطه ورود CLI و Orchestrator مستقل از پروژه را از Skill اختصاصی محصول، Providerهای تحقیق و تولید، اعتبارسنجی، سیاست مجوزها، ابزارهای محدود و پایگاه داده SQLite برای فعالیت‌ها و رویدادها جدا می‌کند.

## مراحل

`QUEUED → RESEARCHING → GENERATING → VALIDATING → READY → PREPARING_MEDIA → CREATING_DRAFT → VERIFYING_WRITE → COMPLETED`

برای خطا و توقف هم مسیرهای مستقل در نظر گرفته شده است. Dry Run پیش از هر تغییر بیرونی خاتمه پیدا می‌کند. اگر نتیجه درخواست ثبت مشخص نباشد، عملیات با جست‌وجوی رکورد احتمالی تطبیق داده می‌شود؛ درخواست ایجاد بدون بررسی تکرار نمی‌شود.

## قابلیت اتکا و استناد

منابع تحقیق با شناسه و نشانی ثبت می‌شوند. اطلاعات متناقض یا نامطمئن از مرحله تولید نهایی کنار گذاشته می‌شوند. پیش‌نویس با Schema تایپ‌شده و قوانین قطعی پروژه بررسی می‌شود.

ابزارهای محدود مسئول اجرای عملیات بیرونی هستند؛ Provider تولید متن دسترسی مستقیم به آن‌ها ندارد. داده محرمانه از Secret Store تأمین می‌شود و عملیات نوشتن به مجوزهای چندلایه وابسته است.

## محدوده

کد بررسی‌شده یک Skill اختصاصی برای محتوای محصول صنعتی و گردش‌کار پیش‌نویس WooCommerce دارد. این به معنی استقرار یک پلتفرم عمومی خودمختار نیست. اتصال سرویس‌های خارجی و پذیرش نهایی همچنان نیازمند آزمون‌اند. جزئیات داخلی Policy، Endpoint و Schema تجاری در این سند عمومی نمی‌شوند.
